# 发布验证

## 自动检查

- Debug / Release 各 99 项单元测试：课表计算、单双周、冲突布局、非本周提示、固定时长、整体周次调整、Room 事务、迁移、导入导出、协议模拟及应用更新检查。
- Room 使用真实 v1 schema 验证迁移到 v2，默认保留既有颜色并关闭固定课时。
- Android Lint、Debug 与 Release 构建。
- 发布包使用 `apksigner verify` 校验签名，发布资产提供 SHA-256。

## 设备验证范围

Android 36 模拟器与 USB 真机验证过课表编辑、文件导入、持久化、周次调整、节次扩展、分页手势与淡色提示。
模拟器验证固定时长的开始/结束联动、配色方案入库。真机数据库升级前后核对原有字段一致。
设备测试覆盖事务导入/编辑/导出、提醒和两个桌面组件。默认设备测试不联网。

## 外部兼容性限制

WakeUp 实验口令路径曾成功解密并完成数据映射和入库验证，但服务端可随时改变兼容策略。
常规设备身份可能被官方服务拒绝。官方 App 对本项目导出格式的接收情况未完全验证。
不将协议模拟测试或本项目导出往返测试视为全部官方版本兼容的证据。

所有仓库内测试数据和截图均为合成演示数据；私有验证文件、个人课程内容、分享口令、设备标识和签名密钥不进入仓库。
