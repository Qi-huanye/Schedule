应用内下载更新，并修复设置页的几处显示问题。

### 应用内更新

- 发现新版本后点「更新」即可在应用内下载，弹窗显示进度，可随时取消；下载完成后直接打开系统安装界面。
- 安装前核对校验值、包名、版本和签名，不通过不会安装；下载失败时可重试或改用浏览器下载。
- 首次更新需在系统设置中允许 Schedule 安装应用。
- 更新说明的标题和列表正常显示，不再出现 Markdown 符号。

### 修复

- 设置背景后，「我的」页向上滚动时顶部面板被截断。
- 背景模糊调到很低时，图片突然缩小。
- 拖动模糊滑条或切换背景选项后，设置区域会跳动一下。
- 切换「显示周末」「每周第一天」等设置时，相邻的选项会闪烁一下。
