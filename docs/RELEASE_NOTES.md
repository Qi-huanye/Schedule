界面精简、自定义背景与应用内更新提示。Android 8.0 及以上可安装。

### 界面与操作

- 「我的」成为唯一的设置页，分为当前课表、外观、数据、关于四组；各页面右上角不再有齿轮。
- 原「课表设置」长表单拆开：学期（开学日期、周数、首课周次，附周次预览）、作息时间（步进调整节数，点选时间）、课程配色、课前提醒，都在「我的」里直接修改。
- 课表页标题显示课表名，点击可跳到任意周，或切换、新建、导入课表。
- 课程详情改为底部面板；编辑课程只保留一个「保存」，并可在编辑页删除课程。
- 上课时间在面板中编辑：星期一键选择，节次和周次网格先点起点、再点终点，单双周直接显示在网格上；节次网格末尾可增加一节。
- 今日页显示「20 分钟后」「进行中」等相对时间，课程卡片使用课程颜色；当天课程结束后显示下一节课。
- 导入与导出重新排列：选择文件、粘贴文本、WakeUp 分享口令三个入口，导入前统一确认。
- 课前提醒点选即生效；精简大量说明文字，隐私与致谢移入「开源许可与隐私」。
- 修复编辑课程、作息时间、导入与导出等页面上下多出空白、底部按钮被遮挡的问题。

### 自定义背景

- 在「我的 → 外观 → 背景图片」选择本机图片作为应用背景，可调整模糊程度和图片位置。
- 可根据图片自动生成浅色与深色主题；在「课程配色」中选择「跟随背景」，课程颜色也取自图片。
- 图片在本机缩放并去除元数据后保存在应用私有目录，不会上传；课表备份不包含背景图片。

### 应用内更新提示

- 打开应用时每天最多自动检查一次 GitHub 正式版，可手动检查、跳过某个版本或关闭自动检查。
- 检查只请求公开的发布信息，不携带课表或设备标识；发现新版本时打开 GitHub 发布页下载，不会自动安装。
