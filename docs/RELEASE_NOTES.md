首个 GitHub 发布版本，Android 8.0 及以上可安装。

### 功能

- 多课表、单双周、课程冲突分栏，支持 ICS / JSON 导入导出与本地备份。
- 周课表左右平滑翻页、非本周提示、空课位淡显其他周课程。
- 自定义每日节数，可在添加课程时扩展晚间节次。
- 开学日期与首课周次分别设置，支持整体调整且保留实际日期。
- 固定课时长自动计算结束时间，四套课程配色方案。
- 今日课程、课前提醒、今日/下一节桌面组件、深浅外观。
- WakeUp 分享口令实验兼容入口：用户主动开启后联网获取，不保证长期服务端兼容。

### 下载与安装

下载 `Schedule-0.2.0.apk`。`SHA256SUMS.txt` 用于核对文件完整性。
发布包关闭调试，沿用项目当前安装版本的签名；可覆盖升级本项目已有安装并保留数据。其他来源签名不同的安装不能直接覆盖，操作前请先导出备份。

无广告、无账号、无统计追踪；课表保存在本机。只有主动使用口令导入时联网。
项目独立开发，与 WakeUp 官方无隶属关系。

### 验证与限制

- Debug / Release 各 80 项单元测试；Room v1 → v2 无损迁移测试。
- 提醒受系统省电策略影响；ICS 不支持全天、跨午夜及月度重复事件。
- 本项目导出的 WakeUp 格式尚未在全部官方版本验证；推荐原生备份保留全部设置。
